# 🐰 Funny Bunny – Meme Sharing Platform

Funny Bunny is a fun and interactive meme-sharing platform where users can create profiles, post memes, like, and comment — all through a clean and secure web app built with Django.

---

## 🚀 Features

- 🖼️ Share and browse memes  
- 👍 Like and 💬 comment on posts  
- 👤 User profiles with authentication  
- 🔐 Secure login system  
- 📱 Responsive front-end (HTML, CSS, JavaScript)

---

## 🛠 Tech Stack

- **Backend:** Python, Django  
- **Frontend:** HTML, CSS, JavaScript  
- **Database:** SQLite  
- **Authentication:** Django built-in auth system
